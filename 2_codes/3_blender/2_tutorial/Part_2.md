  For customization, go to Edit → Preferences → Keymap to modify keyboard shortcuts and other settings. In the Interface section, the Resolution Scale can be increased to 1.25 to make the interface and line width more visible. After making the changes, click Save Preferences.  
  
Mouse navigation is also very important in Blender. The scroll wheel is mainly used for zooming in and out. Shift + Middle Mouse Button allows us to pan the view in different directions. Blender works with three main axes: X, Y, and Z, which help us navigate and position objects in 3D space. In Edit → Preferences → Navigation, Blender also provides Walk and Fly navigation options for moving around the scene
