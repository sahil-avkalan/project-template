Padding  
1) We can use Padding in Auto Layout to maintain horizontal and vertical spacing around the text.  
2) We can also adjust the padding directly by dragging the handles on the canvas.  
3) For example, if we create a Save icon inside an Auto Layout, we can right-click it and go to Copy/Paste As → Copy Properties. Then, we can right-click another icon, such as a Book icon, and select Paste Properties to apply the same properties.  
4) However, this method may have some limitations or may not give the exact result we want.  
5) Therefore, we can adjust the properties manually to achieve a more precise and perfect result.
