Part 11 — Axis Movement and Origin  
  
To define Axis Movement, we first need to understand how the 3D Cursor works. The 3D Cursor can be placed at any location, while the object’s origin point can be set separately.  
  
To set the origin point, select the object and go to:  
  
Object → Set Origin → Origin to 3D Cursor  
  
This allows us to move the origin point to the current position of the 3D Cursor.  
  
Movement Along Different Axes  
  
If we want to move an object in a particular direction, press G (Grab/Move). The object can then be moved freely in any direction.  
  
To constrain the movement to a specific axis:  
  
G + X → Move along the X-axis  
G + Y → Move along the Y-axis  
G + Z → Move along the Z-axis  
  
We can also use Snap to precisely position a vertex or object.  
  
Setting the Origin of a Duplicate Object  
  
If we duplicate a mesh, the duplicate object normally retains its own origin based on the original object. If we want to change its origin, we can use the 3D Cursor as a reference.  
  
For example:  
  
Place the 3D Cursor at the required location.  
Select the object.  
Go to Object → Set Origin → Origin to 3D Cursor.  
The object's origin will move to the 3D Cursor position.  
  
Once the origin has been repositioned, pressing R (Rotate) will rotate the object around the new origin point.  
  
This is useful when we want an object to rotate around a custom pivot/origin point rather than its default center.  
We can move the mesh in any desired direction. If we want to rotate the four corners of the cube without changing or deforming its faces, we can use the Locations option. By selecting Locations, any transformation we apply—such as scaling or rotation—can be performed while keeping the cube’s faces unchanged and maintaining their original orientation.  
  
This feature also works with CAD Transform, allowing us to apply transformations while preserving the shape and structure of the cube.
