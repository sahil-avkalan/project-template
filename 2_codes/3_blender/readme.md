### 2D Projection, Face Selection, Normals, and Measurement

In this part, we learn about **2D Projection and different selection tools** in Blender.

In the **Top View**, we can select the required geometry. By pressing **F**, we can create a face from the selected vertices. When a face is selected, we can use **Shift + Left Click** to add more faces to the selection.

To select edges, we can use **Edge Select**, and with **Shift + S**, we can move the **3D Cursor to the selected element**. To add a new mesh, press **Shift + A**, go to the **Mesh** menu, and select a **Circle**.

We can also select vertices and create a face using the **F** key. The **Knife Tool (K)** is used to cut the mesh. When we make a cut, it creates new geometry, which becomes an important part of the 3D object.

### Normals and Face Orientation

**Normals** are an important part of a 3D object because they define the direction of a face. If the normals are facing the wrong direction, the object may not behave correctly during modeling, shading, or other operations.

To check the direction of the faces, we can enable **Face Orientation** from the **Overlays** menu. The faces are displayed in different colors:

- **Blue** – Front-facing/outward-facing side
- **Red** – Back-facing/inward-facing side

If a face has the wrong orientation, we can select it and press **Alt + N** to open the **Normals** menu, then use **Flip** to reverse its direction.

### Measurement Tool

In the **Overlays** menu, under **Measurement**, we can enable different measurement options such as:

- **Edge Length**
- **Edge Angle**
- **Face Area**
- **Face Angle**

These options help us clearly see the measurements of the selected geometry.

The **Measure Tool** can also be accessed from the toolbar or through the **N menu**. By clicking and dragging between two points, we can measure the distance between them. The measured length is displayed directly in the viewport.

### Units and Precision

In the measurement settings, the units can be set to **Millimeters**, and the **Precision** can be set to **4 decimal places**. This is useful for precision modeling and allows us to work with accurate dimensions.

### AD Transform and SVG Export

We can also use **AD Transform** and set the scaling to **millimeters** when working with precise dimensions.

For exporting vector geometry, we can use **Outline to SVG**. After selecting the required object, we can export it as an **SVG file**. The export settings allow us to adjust options such as **DPI, stroke, and dimensions**.
