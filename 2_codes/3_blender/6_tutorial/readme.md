6 – Blender Viewport and 3D Cursor  
The 3D Cursor is an important tool in Blender. It indicates the location where new objects or meshes will be added.  
To move the 3D Cursor back to the World Origin, press Shift + S and select Cursor to World Origin.  
To add a new mesh or object, press Shift + A. This opens the Add Menu, where you can select options such as Mesh, Curve, etc.  
The Shift + A menu provides various options for adding different types of objects to the scene.  
To change the value of a selected object or setting, you can Shift + Left Click on the relevant value and adjust it.  
You can also use Shift + Right Click to place or reposition the 3D Cursor in the viewport.  
By default, the 3D Cursor is displayed at the center of the scene.  
To move the cursor precisely, use the appropriate cursor-placement tools or coordinates.  
Moving Objects Along Specific Axes  
To move an object, first select it and press G (Grab/Move).  
After pressing G, press X, Y, or Z to constrain the movement to a specific axis.
G + X → Move along the X-axis  
G + Y → Move along the Y-axis  
G + Z → Move along the Z-axis  
You can also move an object freely by using the mouse after pressing G.  
To cancel the movement, press Esc or use the appropriate cancel command.  
For more precise movement, enter a numerical value after selecting the required axis.  
Additional Shortcut  
Shift + D is used to duplicate an object.  
After pressing Shift + D, move the mouse to position the duplicated object.  
You can constrain the duplicate to the X, Y, or Z axis for accurate placement.  
Using these shortcuts makes object manipulation faster and more precise in Blender.
