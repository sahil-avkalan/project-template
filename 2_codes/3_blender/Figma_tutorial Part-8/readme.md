If we want to change the color of a design, we go to Design → Fill and choose the desired color.  
  
If we want to round the edges of a rectangle, we go to Design → Corner Radius and adjust the value.  
  
If we select the text and rectangle together on the Home screen by holding Shift, we can go to Auto Layout in the Design panel and click the + icon. This gives us different layout options, such as Vertical Layout, Horizontal Layout, and Wrap.  
  
In Auto Layout, we can also adjust the horizontal gap between items and set the padding. Using Align Center, we can properly align the text within the layout.  
  
From the Layers panel, we can select the Home screen and switch to the Prototype tab on the right-hand side.  
  
To set the starting point, select the Home screen and click the + icon next to Flow Starting Point. This sets the selected frame as the starting point of the prototype.  
  
To navigate between different screens, select the Home button. A + icon will appear on it.
