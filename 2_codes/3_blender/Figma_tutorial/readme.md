### Figma – Smart English Translation

**Part 1:**  
Now we will learn how to design in Figma. First, we click on **Design** from the left-hand side, which opens the **Figma Editor**. Here, we have the **Toolbar** at the top, with different tools available. On the left-hand side, we have the **Layers panel**, and on the right-hand side, we have the **Properties panel**.

The design is created inside the **Editing Canvas**. At the top, we can open the **Untitled** file and rename it as required. To change the file name, simply click on it. On the left side, we also have the **File Browser**, where we can access our files. At the bottom, there is a **Save** option.

If we double-click on a file, it opens on the canvas, allowing us to edit the design. To organize the design properly, we can use **Frames**. A frame acts as a container for different UI elements and helps keep the design structured.

---

**Part 2:**  
On the left-hand side of the Toolbar, we have the **Frame (F)** tool. By clicking **Frame (F)**, we get options such as **Section**, **Slice (S)**, and **Frame**. After selecting Frame, we can draw a frame directly on the canvas by clicking and dragging.

We can select the **corner handles** of the frame and adjust its size. The width and height can be modified according to our requirements.

If we want to delete a frame, select it from the left-side Layers panel and press the **Delete** key. The frame will be removed from the canvas. We can also select a frame and press **F** on the keyboard to create another frame.

For example, if we want to design for an **iPhone 15 Pro Max (450 × 952)**, we can select the required device frame, and it will automatically be added to the canvas.

---


To insert another frame, we can use the **Frame** tool again and add an additional frame to the screen. We can also press **F** on the keyboard to quickly insert a new frame.

If we want to copy an existing design or element, we can use **Ctrl + C** and then **Ctrl + V** to paste it.
