If we want to fill the entire frame with a rectangle, we can select the rectangle by grabbing its corner and adjusting its dimensions. After selecting the Rectangle tool, we can see its **Width** and **Height** on the right-hand side.

We have placed one rectangle over another. Now, we can go to **Fill**, click on it, and choose the color we want. For example, we can select **Black** and set its **Opacity** to **30%**. To add an effect, we click on **Effects**. This will blur whatever is underneath the rectangle. We can also adjust the intensity of the blur as needed.

To add a logo to the home screen, we go to the **Shape Tools** on the upper-left side of the toolbar and select **Place Image/Video**. Then, we choose the logo file and place it on the canvas. After that, we can adjust its size and position as required.

If we hold the **Alt** key on the keyboard, it shows the distance between different elements or the specific pixel measurements between them.

On the right-hand side, we can see **Layout Grid**. By clicking on the Layout Grid settings, we can change its **size, color, and opacity**.

To add text to the home screen, we click on the **Text tool (T)** in the toolbar and place the text wherever we want. To adjust the text size, we go to the **Text** section under the Design panel and enter the required value. We can also align the text as needed.

The shortcut key for the **Frame tool** is **F**, which changes the cursor to the Frame tool. We can rename the frame—for example, I rename it **Navigation**.

Now, by selecting the **Navigation** frame and pressing **Shift + 2**, Figma will zoom in on the selected frame.

To adjust the spacing between elements, we first select one rectangle, then hold the **Shift** key and select the other rectangles. After that, under the Design panel, we click on **Distribute Horizontal Spacing**, which automatically makes the spacing equal.

If we want to create a hole in a shape, we can use **Subtract Selection** from the toolbar. The shortcut **Shift + X** can be used to swap between the fill and stroke.

To group elements, we select the **pin and rectangle**, then right-click and choose **Group Selection**. Alternatively, we can use **Ctrl + G** to create a group. After creating the group, we can click on it and rename it as needed.

If we click on a rectangle in the **Layers** panel, we can hide or show that element.

With the **Pen Tool (P)**, we can create custom shapes and vectors. Whenever we draw a shape, Figma creates vector points along the path. If we want to move a specific point to another location, we can select the **Move Tool**, click on the required point, and drag it to the desired position.
