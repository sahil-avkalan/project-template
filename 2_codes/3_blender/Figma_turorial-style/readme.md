Styles in Figma  
1) Styles allow us to reuse properties and instantly update them throughout the entire file.  
2) Color Styles can be applied to Fills, Strokes, and Text as a fill.  
3) We can also create different types of styles, such as Text Styles, Effect Styles, and Layout Grid Styles.  
4) Local Styles belong to the current file. They can also be published and shared with the Team Library for reuse across designs.  
5) We do not need to create all styles before starting the design.
