Part 5  
  
We can use the Alt key on the keyboard to scale an object from its center. When we scale the object, it will grow or shrink from the center rather than from one side.  
  
If we want to select or work with the edges, we can use the Shift key. Double-clicking an object takes us into Edit Mode, where we can make more detailed changes.  
  
Now, in the Design panel, we can go to Corner Radius and adjust the radius as needed. We can also go to the Fill section and change the fill color. We can adjust the appearance as required, such as making the design thicker or thinner and choosing the desired color.  
  
To group multiple objects together, select them and press Ctrl + G. This allows us to move and manage them as a single group.  
  
If we want to explore more resources, we can click Explore Community from the top-left corner. From there, we can go back to Files, and then select Explore Community from the lower section. This will open Figma Community, where we can find different resources such as free and paid templates, plugins, and UI kits.  
  
We can use these resources in different projects. For example, we can search for a specific resource using the search bar. Once we find the required resource, we can click Open in Figma, and the template will open in Figma.  
  
On the top-left side, under Pages, we can see different icon styles such as Regular, Thin, Light, Bold, and Fill. We can choose the style we need.  
  
If we want to use an icon, we can double-click it. The icon will open in the editing area, where we can select and copy it using Ctrl + C.  
  
After that, we can go back to Files and open the project we were working on. Double-click the required file, zoom into the desired area, and press Shift + 2 to fit the selected object into view.
