Variants  
  
If we apply a slash ( / ) inside a component, it helps us organize the component into different variants. For example, we can create Property 1, Property 2, Property 3, etc. The slash is used to create a folder-like structure for organizing the data, such as a Component Set.  
  
Component Variants  
  
If we take a Frame and create four separate rectangles inside it, we can use them as different button variants. We can write “Button” as the text inside the rectangle. We can also use the Windows key to select or group the elements.  
  
After creating the variants, we can go to Current Variant and click the + icon. Under Name, we can enter “Button”, and under Value, we can enter something like “Hello”. This allows us to define different properties and values for the component.
