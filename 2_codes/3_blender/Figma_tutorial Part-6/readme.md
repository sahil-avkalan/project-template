**Grouping and Components:**  
To group objects, select the required objects and use the **Group** option. After grouping, the objects can be handled as a single unit. If you want to zoom out, you can use the **Navigation** controls to adjust the view.

To create a component, select the required object and click **Create Component**. Once the component is created, it is added to the component section, and its color/icon changes to indicate that it is now a component.

We can also select a component from the **Navigation bar** and drag and drop it anywhere on the canvas. If we want to make changes to the original component, we can edit its properties and those changes will be reflected in its instances.

### Constraints

Using **Constraints**, we can control how an object behaves when its parent frame or screen is resized. We can select a component and set its constraints to **Left, Right, Top, Bottom, or Center**.

For example, if we select **Left and Right**, the object remains attached to both the left and right sides when the screen is resized. However, in the example shown, the **bottom side does not remain locked**.

To fix this, we can go back to **Navigation**, select the component, and set its **Bottom constraint**.
