1) I used the Text Tool to create the button text.  
2) I used the Fill option to apply colour to the button.  
3) For the Stroke, I set the stroke weight to 10.  
4) I used separate Frames to organize the different elements of the design.  
5) I used the Text Tool to add the required text inside the frames.  
6) For the icon, I searched on Google, copied the required icon, and pasted it into Figma.  
7) After creating the button, I clicked on Create Component to convert it into a component.  
8) To create an Instance of the component, I clicked on the diamond icon and created its instance.
