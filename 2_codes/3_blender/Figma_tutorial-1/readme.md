Frame (F):  
In the Frame (F) option, we can create a frame and use it for different design purposes. The shortcut key for creating a frame is F. Frames are commonly used to create designs such as flyers, brochures, posters, and other layouts.  
  
Shapes:  
We can add different shapes, such as a rectangle. By adjusting the corner radius, we can make the corners smooth and rounded.  
  
Canvas:  
We can create a rectangle inside the canvas. The rectangle can be resized according to our requirements. To group multiple objects, select them and press Ctrl + G.  
  
Constraints:  
Constraints help us control how an object behaves when the frame is resized. We can apply Horizontal and Vertical constraints. For example, selecting Left and Right constraints allows the object's width to adjust when the frame width changes.  
  
Alignment:  
If we create an ellipse inside a frame, we can use the Align options in the Design panel. For example, selecting Align Left positions the ellipse along the left side of the frame.  
  
Distribution:  
If we have multiple objects, such as rectangles or ellipses, we can select them together and use Tidy Up to arrange them with equal spacing.  
  
Renaming Layers:  
Layers can be renamed according to their purpose. Under the Layers panel, we can select an object and rename it using the Rename option.  
  
Plugins & Widgets:  
Under Actions, we can access Plugins and Widgets. We can search for the required plugin or widget and download it. We can also use the Sort option to organize the results and select the required plugin.  
  
Color Styles:  
Figma also provides different color and styling options, such as Gradients, Patterns, Images, Video, and Shader Beta, which can be used to enhance the design.
