In this section, we create a geometry using the **Extrude** tool. To select a vertex from our mesh, we go into **Edit Mode** and press **M**. Then, by selecting **At Cursor**, we can convert our mesh into a **single vertex**.

We can create the entire geometry using this **single vertex**. After deleting the face, we select the single vertex and edges again and use the **Fill (F)** command to create a face.
