Variables are used to easily reuse and update the same value across multiple places in a Figma design.  
1) On the left-hand side, click on the Variables option.  
2) Under Collections, click the + icon and select Create Collection.  
3) Choose Color as the variable type.  
4) Create a variable and give it a suitable name, such as Primary Color.  
5) To apply the variable, select the button or vector you want to modify.  
6) You can also apply it directly from the Fill section:  
Go to Fill.  
Click on Apply Styles and Variables.  
Select the required variable.  
Choose the color variable you created.  
7) The created variable can also be viewed and managed through Libraries.  
Purpose
