### Part 18

In this part, we will learn about **Loop Cut, Inset, Knife Tool, and Bevel**.

We use the **Loop Cut** tool to add additional edge loops to our mesh. The shortcut key is **Ctrl + R**. If we want to add multiple loop cuts at once, we can use the **scroll wheel** to increase the number of cuts.

The **Offset Edge Loop Cut** is not always very precise because its **Factor** is based on a percentage. Also, if the mesh contains a **non-quad face (N-gon)**, the loop cut may not be able to pass through it properly.

For inserting geometry inside a face, we use the **Inset** tool. Its shortcut key is **I**. First, select the desired face and press **I** to create an inset. This creates a smaller face inside the original face.

If we select multiple faces and want to inset each face separately, we can enable the **Individual** option in the **Inset Faces** settings.

The **Knife Tool** has the shortcut key **K**. It allows us to manually create cuts on our geometry wherever required, giving us greater control over the mesh topology.

For creating bevels, we use **Ctrl + B**. The Bevel tool allows us to adjust various parameters such as **Width, Segments, Shape, Material, and Index** according to our requirements.
