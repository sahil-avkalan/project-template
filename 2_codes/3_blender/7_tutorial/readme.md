## Part 7— Blender Tutorial Notes

I watched the remaining Blender video tutorials and noted the concepts and shortcuts covered in them. The main topics were **Origins, Object Mode, Edit Mode, the 3D Cursor, duplication, and separating objects**.

### Origins and Objects

In Blender, every object has its own **Origin Point**. The origin represents the reference or center point of the object and is important for transformations such as moving, rotating, and scaling.

When we add a mesh, such as a **Cube**, Blender creates an object with its own origin point. Blender also contains default objects such as the **Camera and Light**.

### Duplicating and Naming Objects

We can duplicate an object using **Shift + D**. After duplicating an object, the duplicate becomes a separate object.

To rename an object, we can select it and press **F2**, then enter the required name.

### Separating Parts

If multiple parts of a mesh are present within the same object, we can use **P (Separate)** in Edit Mode. The Separate option allows us to create a new object from the selected geometry.

For example, if a cube contains separate parts and we select one part in Edit Mode, pressing **P** allows us to separate that selection into a new object.

### 3D Cursor

The **3D Cursor** is an important tool in Blender. It can be moved to different locations and is used as a reference point for adding objects, positioning geometry, and performing transformations.

The **Shift + S** shortcut opens the **Snap menu**, which provides options such as moving the selection to the 3D Cursor or moving the 3D Cursor to the selected object/geometry.

The **Cursor to Selected** option moves the 3D Cursor to the center of the selected geometry.

### Origin and 3D Cursor

The object's **Origin Point** and the **3D Cursor** are different. The origin belongs to the object, while the 3D Cursor is a separate reference point that can be positioned anywhere in the 3D viewport.

When working with multiple objects, it is important to understand which origin point is being used as the reference for transformations.

### Edit Mode and Object Mode

**Object Mode** is mainly used to work with complete objects, while **Edit Mode** is used to modify the actual geometry of an object, such as its vertices, edges, and faces.

If we duplicate an object in Object Mode, we create another object. In Edit Mode, however, we work directly with the geometry inside the selected object.

These tutorials helped me understand how **object origins, the 3D Cursor, snapping, duplication, separation, Object Mode, and Edit Mode** work together in Blender.
