Part-12
In this section, we will learn about different **Blender shortcuts** and how to use them effectively.

First, **Quad View** can be opened using **Ctrl + Alt + Q**, which gives us the classic four-view layout. We can use **7, 9, 1, and 3** to switch between different views.

It is important to keep **Statistics** visible because they provide useful information while working. To enable them, go to **Overlays** and turn on **Statistics**. The statistics will then be displayed in the viewport.

For **Viewport Shading**, press **Z** to open the shading pie menu. It provides options such as **Rendered, Material Preview, Solid, and Wireframe**. Pressing **Shift + Z** switches directly to the **Rendered** view.

**Snapping** should generally be kept enabled when precise positioning is required. Click the small **magnet icon** to turn it on, and select **Vertex** from the snapping options. To quickly toggle snapping on or off, use **Shift + Tab**.

We can also create our own **custom shortcuts** according to our workflow. Press **Q** to open the **Quick Favorites** menu. Commands that we frequently use can be added to this menu.

For example, go to **Object → Snap → Cursor to World Origin**, right-click on the command, and select **Add to Quick Favorites**. Similarly, right-click on **Selection to Cursor** and add it to Quick Favorites. We can also select our mesh, right-click, go to **Set Origin → Origin to 3D Cursor**, right-click on the command, and add it to Quick Favorites.

After adding these commands, press **Q** to open the Quick Favorites menu and quickly select **Selection to Cursor** or any other command that we have added.

The **Right-Click Context Menu** is also a powerful shortcut menu. Depending on what we have selected, it provides different relevant options. For example, if we select the **Camera** and right-click, Blender displays camera-related options. The same concept can be used with **Lights** and other objects.

Blender also provides useful **tips and shortcuts in the status bar** at the bottom whenever we perform an operation or action.

Now, if we select our mesh, such as a **Cube**, and press **G** to move it, Blender provides several secondary shortcuts and options related to the Move operation.

When we are working with an object, we can also press **Spacebar** to open the search menu and search for a particular command or operation instead of manually navigating through the menus.

For example, press **Shift + D** to duplicate the object. Then press **Spacebar** and search for **Join**. The search result shows that the shortcut for Join is **Ctrl + J**. The Join operation is performed in **Edit Mode** when working with mesh components.

For working with separate or loose objects, we can use **Ctrl + L** to access the relevant linking options. To separate mesh components, press **P** to open the **Separate** menu, then select **Selection**. This allows the selected geometry to be separated into a new object.
