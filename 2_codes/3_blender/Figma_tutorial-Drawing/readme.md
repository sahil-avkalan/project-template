1) Frame Creation:  
I used Frames to create the main layout and designed a card within the frame.  
2) Adding Text:  
I added text inside the card and arranged it according to the required design.  
3) Applying Auto Layout:  
I converted the card into Auto Layout to manage its structure and spacing efficiently.  
4) Fill, Stroke, and Radius:  
I applied Fill and Stroke properties to the card and used Corner Radius to give it smooth, rounded corners.  
5) Gap and Padding:  
I used Gap to maintain consistent spacing between elements and Padding to maintain proper spacing between the content and the card boundaries.  
6) Typography:  
I also applied Typography settings to maintain proper font size, weight, alignment, and text styling.  
7) Adding Icons:  
I searched for the required icon on Google, copied it, and pasted it into the Figma design.  
8) Using Multiple Frames:  
I created multiple frames to represent different sections and used different colors for each frame to clearly distinguish between them.
