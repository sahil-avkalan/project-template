1) Creating a Button:  
First, I created a button using the Text tool.  
There are total 9 images  
2) Styling the Button:  
I applied a white color to the button using the Stroke option and set the corner radius to 100 to give it a rounded shape.  
3) Applying Auto Layout:  
Next, I applied Auto Layout to the button. In the Alignment settings, I set the Gap to 50 and adjusted the Padding to 30 and 15.  
4) Creating a Variant:  
I created a variant for the component and set its opacity to 50% to represent a different state.  
5) Setting Component Properties:  
In the component properties, I created a State property and added a Hovered state.  
6) Impact on Instances:  
If I make any changes to the Hovered state of the component, those changes are automatically reflected in its instances.  
7) Benefits of Components and Variants:  
Components and variants help maintain consistency throughout the design and make it easier to manage multiple elements.
