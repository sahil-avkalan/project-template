To properly position the Home icon, select the Home icon and go to the Design panel. Under Constraints, set the horizontal and vertical constraints to Left and Bottom.  
  
Now, click on the Location option and go to Constraints. Set the icon to Center and Bottom. Then, click on Auto and select the appropriate option from the right or bottom side.  
  
When we click on the Home screen, we can adjust the icon’s size. The icon maintains its position relative to the selected area, so it can remain properly aligned on different device sizes.  
  
To duplicate an element, press Ctrl + D. We can also drag the duplicated element to another location on the screen.  
  
If we want to insert a new element, click Insert. This allows us to add different elements to the screen.  
  
For text, first click anywhere on the screen to focus on the desired area, then press Shift + T to activate the Text tool. After that, click where you want to add the text and start typing.  
  
If you want to select a particular text layer, simply click on it. The keyboard arrow keys can be used to move the selected text or element around the screen.  
  
To move the text more precisely, select it and use the arrow keys. In the Components section, click the required component twice to edit or modify it.  
  
The Location Card is another useful component. In the Location Card, we can place different details or information. If we click and drag the card, we can reposition it wherever we want—for example, toward the right side.  
  
In Landscape mode, we can check how the layout behaves and whether the navigation overlaps with other elements. We can select the navigation bar and move it to the required side.  
  
To select the card, hold Shift and click on the required card. Once selected, we can adjust the card’s position and spacing from the center line.  
  
We can also insert images by selecting a Rectangle and then using the Fill option. From the Fill settings, select Image/Video to add an image or video. This allows us to add the required images to our design.We select the image and click Open.
