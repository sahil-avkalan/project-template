1) In Auto Layout, we have 9 alignment options.  
2) The alignment options depend on the gap value set in the Auto Layout. For example, if the gap is set to 10, the alignment behavior will depend on that spacing.  
3) If we set the gap to Auto, the alignment options may appear slightly different.  
When we change the Auto Layout direction from Horizontal to Vertical and keep the gap set to Auto, the available alignment options also change according to the layout direction.  
4) In the Auto Layout settings, there is a Baseline Alignment option. We can select Align Text Baseline from this setting.  
5) Baseline alignment is mainly useful when working with two or more text elements, so that their text sits on the same baseline.
