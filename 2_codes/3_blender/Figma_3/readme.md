1) I used a frame to create this design and placed the required elements inside it.  
2) I used the Text Tool (T) to add text inside the frame.  
3) To add the logo, I searched for an image on Google, copied it, and pasted it onto the Figma canvas using right-click and Paste.  
4) I used the Fill option to apply colours to the elements.  
5) For the stroke, I set the stroke weight to 50.  
6) I also used Auto Layout to arrange the text vertically.
