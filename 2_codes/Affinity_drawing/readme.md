1: Pen Tool  
  
I used the Pen Tool to draw lines and create different shapes. It helped me create and connect points accurately in my drawings.  
  
Step 2: Ellipse Tool  
  
I used the Ellipse Tool to create circles and other circular shapes. This tool helped me maintain accurate and consistent shapes in both drawings.  
  
Step 3: Text Tool  
  
I used the Text Tool to add text, numbers, and labels to my drawings. It is useful for describing different parts of a drawing and providing additional information.  
  
Step 4: Dashed Line Style  
  
I used the Dashed Line Style to create lines with gaps between their segments. By adjusting the dash and gap settings, I could create dashed or dotted lines to represent different features in my drawings.  
  
Step 5: Line Width  
  
I used the Line Width setting to adjust the thickness of the lines created with the Pen Tool.
