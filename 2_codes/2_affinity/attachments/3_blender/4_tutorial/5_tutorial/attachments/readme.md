### Part 5 – Blender Mesh Modeling and Selection

- In Blender, the **3D viewport** is used to work with objects and view the 3D scene from different angles.
- Blender is a **3D modeling program** that provides a 3D space for creating and editing objects.
- Blender mainly provides two important modes for working with objects:
    - **Object Mode** – used to select, move, rotate, scale, and manage complete objects.
    - **Edit Mode** – used to modify the geometry of an object, such as its vertices, edges, and faces.
- For example, if we select a **cube** in Object Mode, the entire cube is selected as one object.
- If we want to edit a particular part of the cube, such as a **face**, we need to enter **Edit Mode**.
- In Edit Mode, Blender allows us to work with different components of the mesh:
    - **Vertex** – a single point of the mesh.
    - **Edge** – a line connecting two vertices.
    - **Face** – a surface enclosed by edges.
- The mesh components can be selected individually or in groups.

### Selection Shortcuts

- Blender provides three main mesh selection modes:
    - **1** – Vertex Select
    - **2** – Edge Select
    - **3** – Face Select
- These shortcuts allow us to quickly switch between vertex, edge, and face selection modes.
- To select an **edge loop**, we can use **Alt + Left Click** on an edge.
- **Alt + Right Click** can be used for loop-related selection depending on the selection context.
- To increase the current selection, use the **Select More** command; to reduce it, use **Select Less**.
- The selection can be expanded or reduced using the appropriate Blender selection shortcuts.

### Circle Selection

- Press **C** to activate **Circle Select**.
- After activating Circle Select, move the mouse over the required vertices, edges, or faces to select them.
- The size of the selection circle can be **increased or decreased using the mouse wheel**.
- This makes it easier to select multiple mesh elements at once, especially when working on larger or more detailed models.

### Mesh Selection Workflow

- First, select the object and enter **Edit Mode**.
- Choose whether you want to work with **vertices, edges, or faces**.
- Select the required geometry according to the operation you want to perform.
- Different selection methods can be used to efficiently select a single element, a group of elements, or an entire loop.
- These selection tools are important for efficiently editing and modifying a 3D mesh in Blender.
