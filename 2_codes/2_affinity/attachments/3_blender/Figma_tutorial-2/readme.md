**Constraints**, if we place a rectangle inside a frame and select **Horizontal → Right**, the rectangle will stay attached to the right side when we resize the frame from the right side. If we select **Center**, the rectangle will remain centered while the frame is resized.

The same can be applied to the **Vertical** constraints as well, such as **Top, Bottom, or Center**.

When we place and group an object, such as a rectangle, inside a frame, we can access the **Constraints** options. However, when we select an object directly from the **Shape Tools**, the Constraints option is not available in the same way.

### Auto Layout

With **Auto Layout**, when we type text inside a frame, the frame automatically adjusts its size and creates enough space to accommodate the content.

Auto Layout provides options such as **Vertical Layout, Horizontal Layout, and Wrap**.

Using **Horizontal Gap**, we can create and control the spacing between two text elements.
