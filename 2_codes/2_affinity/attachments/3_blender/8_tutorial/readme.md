## Part 8 — Blender: Transformations and Proportional Editing

### Transforming Objects

In Blender, an object can be transformed either in **Object Mode** or **Edit Mode**. First, select the object and press **X** to delete it. To move the **3D Cursor**, use **Shift + Right Click** and place it at the desired location.

To open the **Transform** panel, press **N**. This panel provides options such as **Location, Rotation, Scale, and Dimensions**. The Location values can be changed by clicking on them and dragging, or by entering specific values.

For example, the object can be positioned by setting its coordinates to:

- **X = 3 mm**
- **Y = 1.5 mm**
- **Z = 1 mm**

The **Scale** option is used to increase or decrease the size of an object. To return the scale to normal, press **Ctrl + A** and select **Apply Scale**. Similarly, Blender provides tools such as **Move, Rotate, and Scale** under the Transform tools.

### Transform Orientation and Movement

The selected object can be moved along a specific direction using the **G (Grab/Move)** command. After pressing **G**, press **X, Y, or Z** to constrain the movement to that particular axis.

The **Transform Orientation** can be changed from **Global** to **Local**. In Local orientation, the Move tool works according to the object's local axes rather than the global axes.

For example:

- **G + X** → Move along the X-axis
- **G + Y** → Move along the Y-axis
- **G + Z** → Move along the Z-axis

You can also move an object freely and then constrain it to a particular axis. For example, after pressing **G**, pressing **X** restricts the movement to the X direction.

### Rotation

To rotate an object, press **R (Rotate)**. The rotation can also be constrained to a specific axis.

For example, press **R**, then **X**, and enter **45°** to rotate the object by 45 degrees around the X-axis.

### Pivot Point

The **Pivot Point** determines the point around which an object or mesh is transformed. Blender provides different pivot options. An object normally has its own pivot point, but the pivot point can be changed when required.

### Proportional Editing

**Proportional Editing** allows you to move, rotate, or scale a selected vertex or part of a mesh while smoothly affecting the surrounding geometry.

To use Proportional Editing:

1. Enter **Edit Mode** and select a vertex.
2. Enable **Proportional Editing**.
3. Use **G** to move the selected vertex.
4. A circular influence area appears around the selected vertex.
5. Use the **mouse wheel** to increase or decrease the influence radius.
6. The surrounding vertices are moved smoothly according to the selected vertex.

Proportional Editing can also be used with **Rotate** and **Scale**. It is useful for creating smooth and natural deformations in a mesh.

To disable Proportional Editing, simply turn off the **Proportional Editing** option in the toolbar.
