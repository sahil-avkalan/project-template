In Blender, there are two types of add-ons. The first type comes with Blender and is already part of its code, while the second type is developed externally and can be integrated into Blender.  
  
To manage add-ons, go to Edit → Preferences → Add-ons. From there, you can search for the required add-on and install or enable it. Once enabled, its options can be accessed from the Sidebar, which can be opened by pressing N.  
  
External add-ons are usually downloaded from websites. If you want to remove an add-on, go to Edit → Preferences → Add-ons, select the add-on, and click Remove. Blender’s built-in add-ons are also maintained and updated from time to time.  
  
Sometimes, adding one add-on may override or conflict with another add-on. Most add-ons have their own documentation or wiki pages that explain their features and usage. After making changes to the add-ons, click Save Preferences to save the settings.
In Blender, if we want to work in millimeters, we need to adjust the unit settings. To open the required options, we can press N. For scaling and unit settings, go to Scene Properties.  
  
First, change the Units settings. Set the Unit Scale to 0.001 so that Blender works properly in millimeters. After setting the unit scale, we can work with dimensions in millimeters.  
  
To check the grid settings, open the Grid options. The grid can be adjusted according to our requirements. If the grid appears too large, we can reduce its scale to 0.001 to make it suitable for millimeter-based modeling.
