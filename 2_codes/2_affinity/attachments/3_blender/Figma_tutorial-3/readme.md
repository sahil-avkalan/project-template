### Brand Colours and Semantic Colours

**Grays:**  
If we create a rectangle inside a frame and duplicate it using **Alt**, then go to **Fill** and press **Shift + Down**, the rectangle will become a shade of gray. If we duplicate the same rectangle again and press **Shift + Down**, it will become slightly darker than the previous one.

**Brand Primary:**  
First, create a rectangle and apply a color from the **Fill** section. To make the color darker, click the **+ icon** in the Fill section and set the opacity to **20%**. Then select the **Eyedropper (I) tool** and click on the rectangle. This will create a darker version of the selected color.

**Colour Styles:**  
To create a color style, create a rectangle on the canvas and choose a color, such as **red**, from the Fill section. Then click the **four-dot icon** and select the **+ icon** next to Libraries. A new window will open where we can select **Style**.
