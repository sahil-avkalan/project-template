Design Systems  
1) Before starting any User Interface (UI), we need to understand the components, guidelines, and rules that are used throughout the app, especially on the main screen.  
2) A design system is not only for apps; it can also be used for marketing-related designs and other digital products.  
3) It contains guidelines and codes that help maintain consistency across the design.  
4) A design system can include elements such as buttons, colours, and other UI elements.  
5) It can be used for both mobile apps and websites, and it is also relevant to UX design.  
6) For apps or websites, we need to define and organize the design elements properly.  
7) A design system may include a colour palette, typography, basic components, and atomic components.  
8) It can also include elements such as pop-ups and buttons. Once these elements are properly organized, the design system becomes easier to use and maintain.
